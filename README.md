# digital-image-authenticity
An image authenticity system that combines digital forensics and AI to detect potential manipulation and create evidence-based reports.
This is my first major personal project. It explores how digital forensics and AI can be used to analyze images and identify potential manipulation or synthetic content.

__Current Features__
SHA-256 digital fingerprinting,
Unique image analysis IDs,
EXIF metadata extraction,
Image property analysis,
JPEG quantization analysis,
Image-to-image comparison,
JSON evidence generation.

__Planned Features__
Perceptual image hashing,
Pixel-level forensic analysis,
AI-generated image detection,
Manipulation detection,
Evidence scoring,
Automated PDF evidence reports.

The project is currently under development.
